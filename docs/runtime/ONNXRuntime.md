# ONNXRuntime

* 版本：1.20.1

## 安装教程

```
wget https://github.com/microsoft/onnxruntime/releases/download/v1.20.1/onnxruntime-linux-x64-1.20.1.tgz
tar -zxvf onnxruntime-linux-x64-1.20.1.tgz
mv onnxruntime-linux-x64-1.20.1 onnxruntime
cd onnxruntime
cp -r lib lib64
mkdir onnxruntime
cp -r include/* onnxruntime
mv onnxruntime include
```
